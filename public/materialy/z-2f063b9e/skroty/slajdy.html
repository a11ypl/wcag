Accessibility First

Skróty klawiaturowe dla audytora

Windows i Mac · Accessibility First

1

System operacyjny (1/2)

  • Przełącz aplikację: Windows Alt+Tab · Mac Cmd+Tab
  • Pokaż pulpit: Windows Win+D · Mac Fn+H albo Cmd+F3 (klawisz Mission Control)
  • Zablokuj ekran, gdy odchodzisz od komputera: Windows Win+L · Mac Ctrl+Cmd+Q
  • Zamknij aplikację: Windows Alt+F4 · Mac Cmd+Q
  • Zamknij okno albo kartę: Windows Ctrl+W · Mac Cmd+W
2

System operacyjny (2/2)

  • Zminimalizuj okno: Windows Win+strzałka w dół · Mac Cmd+M
  • Wyszukiwanie w systemie: Windows Win+S · Mac Cmd+Spacja (Spotlight)
  • Menedżer plików: Windows Win+E (Eksplorator plików) · Mac Option+Cmd+Spacja (okno wyszukiwania Findera)
  • Zawieszona aplikacja: Windows Ctrl+Shift+Esc (Menedżer zadań) · Mac Option+Cmd+Esc (Wymuś koniec)
3

Przeglądarka: karty i pasek adresu (1/2)

  • Nowa karta: Windows Ctrl+T · Mac Cmd+T
  • Zamknij kartę: Windows Ctrl+W · Mac Cmd+W
  • Przywróć zamkniętą kartę: Windows Ctrl+Shift+T · Mac Cmd+Shift+T
  • Następna karta: Windows Ctrl+Tab · Mac Ctrl+Tab albo Cmd+Option+strzałka w prawo
  • Poprzednia karta: Windows Ctrl+Shift+Tab · Mac Ctrl+Shift+Tab albo Cmd+Option+strzałka w lewo
4

Przeglądarka: karty i pasek adresu (2/2)

  • Karta o numerze od 1 do 8: Windows od Ctrl+1 do Ctrl+8 · Mac od Cmd+1 do Cmd+8
  • Ostatnia karta: Windows Ctrl+9 · Mac Cmd+9
  • Przejdź do paska adresu i zaznacz adres (np. do raportu): Windows Ctrl+L · Mac Cmd+L
  • Dopisz www. i .com do wpisanej nazwy: Windows wpisz nazwę, potem Ctrl+Enter · Mac wpisz nazwę, potem Ctrl+Return
  • Otwórz wpisany adres w nowej karcie: Windows wpisz adres, potem Alt+Enter · Mac wpisz adres, potem Cmd+Return (karta w tle)
5

Odświeżanie i zakładki

  • Odśwież stronę: Windows F5 albo Ctrl+R · Mac Cmd+R
  • Odśwież bez pamięci podręcznej, np. po poprawce wdrożonej przez dewelopera: Windows Ctrl+F5 albo Ctrl+Shift+R · Mac Cmd+Shift+R
  • Dodaj stronę do zakładek: Windows Ctrl+D · Mac Cmd+D
  • Dodaj wszystkie otwarte karty do zakładek, np. całą próbę stron z audytu: Windows Ctrl+Shift+D · Mac Cmd+Shift+D
6

Wyszukiwanie na stronie

  • Znajdź na stronie: Windows Ctrl+F · Mac Cmd+F
  • Następne trafienie: Windows Enter albo Ctrl+G · Mac Cmd+G
  • Poprzednie trafienie: Windows Shift+Enter albo Ctrl+Shift+G · Mac Cmd+Shift+G
7

Edycja tekstu do raportu (1/3)

  • Kopiuj: Windows Ctrl+C · Mac Cmd+C
  • Wytnij: Windows Ctrl+X · Mac Cmd+X
  • Wklej: Windows Ctrl+V · Mac Cmd+V
  • Wklej bez formatowania: Windows Ctrl+Shift+V · Mac Option+Shift+Cmd+V
  • Cofnij: Windows Ctrl+Z · Mac Cmd+Z
8

Edycja tekstu do raportu (2/3)

  • Ponów: Windows Ctrl+Y · Mac Cmd+Shift+Z
  • Zaznacz wszystko: Windows Ctrl+A · Mac Cmd+A
  • Skok o słowo (z Shift: zaznaczanie): Windows Ctrl+strzałka w lewo albo Ctrl+strzałka w prawo · Mac Option+strzałka w lewo albo Option+strzałka w prawo
  • Początek albo koniec linii: Windows Home albo End · Mac Cmd+strzałka w lewo albo Cmd+strzałka w prawo
  • Początek albo koniec dokumentu: Windows Ctrl+Home albo Ctrl+End · Mac Cmd+strzałka w górę albo Cmd+strzałka w dół
9

Edycja tekstu do raportu (3/3)

  • Historia schowka: Windows Win+V · Mac Cmd+Spacja, potem Cmd+4 (macOS 26 Tahoe i nowsze)
10

Narzędzia deweloperskie (1/2)

  • Otwórz narzędzia deweloperskie: Windows F12 albo Ctrl+Shift+I · Mac Cmd+Option+I
  • Zbadaj element: wskaż go na stronie: Windows Ctrl+Shift+C · Mac Cmd+Shift+C
  • Konsola: Windows Ctrl+Shift+J · Mac Cmd+Option+J
  • Tryb urządzenia, np. szerokość 320 pikseli (WCAG 1.4.10): Windows Ctrl+Shift+M · Mac Cmd+Shift+M
  • Menu poleceń, np. wpisz „Rendering”, żeby symulować zaburzenia widzenia barw: Windows Ctrl+Shift+P · Mac Cmd+Shift+P
11

Narzędzia deweloperskie (2/2)

  • Szukaj w kodzie strony (panel Elements): Windows Ctrl+F · Mac Cmd+F
  • Okno incognito: strona bez rozszerzeń i bez zalogowania: Windows Ctrl+Shift+N · Mac Cmd+Shift+N
12

Powiększanie, zrzuty i nagrania (1/2)

  • Powiększ albo pomniejsz stronę (WCAG 1.4.4, 1.4.10): Windows Ctrl+plus albo Ctrl+minus · Mac Cmd+plus albo Cmd+minus
  • Wróć do 100%: Windows Ctrl+0 · Mac Cmd+0
  • Pełny ekran: Windows F11 · Mac Ctrl+Cmd+F
  • Zrzut fragmentu ekranu: Windows Win+Shift+S · Mac Cmd+Shift+4
  • Zrzut jednego okna: Windows Win+Shift+S, potem tryb okna na pasku narzędzia · Mac Cmd+Shift+4, potem Spacja i kliknij okno
13

Powiększanie, zrzuty i nagrania (2/2)

  • Zrzut całego ekranu: Windows PrtScn · Mac Cmd+Shift+3
  • Nagranie ekranu, np. ginącego fokusu (WCAG 2.4.7): Windows Win+Alt+R (Xbox Game Bar, nagrywa aktywne okno) · Mac Cmd+Shift+5
  • Tryb wysokiego kontrastu: Windows lewy Alt+lewy Shift+PrtScn · Mac Option+Cmd+F5 (panel skrótów dostępności)
14

Okna obok siebie

  • Okno na lewą albo prawą połowę ekranu: Windows Win+strzałka w lewo albo Win+strzałka w prawo · Mac Fn+Ctrl+strzałka w lewo albo Fn+Ctrl+strzałka w prawo
  • Okno na cały ekran, bez trybu pełnoekranowego: Windows Win+strzałka w górę · Mac Fn+Ctrl+F
  • Przełącz okna tej samej aplikacji: Windows brak stałego skrótu · Mac Cmd+ (klawisz grawisu, jego miejsce zależy od układu klawiatury)`
  • Przenieś okno na drugi monitor: Windows Win+Shift+strzałka w lewo albo Win+Shift+strzałka w prawo · Mac brak domyślnego skrótu
15

Test klawiaturą na stronie (1/2)

  • Tab · Fokus przechodzi do następnego elementu interaktywnego, jest widoczny i idzie w logicznej kolejności (WCAG 2.1.1, 2.4.3, 2.4.7)
  • Shift+Tab · Fokus wraca do poprzedniego elementu i nigdzie nie utyka (WCAG 2.1.2)
  • Enter · Uruchamia łącze i przycisk (WCAG 2.1.1)
  • Spacja · Uruchamia przycisk, zaznacza pole wyboru. Gdy fokus nie jest na kontrolce, przewija stronę
  • strzałki · Poruszają się w grupie przycisków opcji, na liście rozwijanej, w menu i w kartach. Gdy fokus nie jest na kontrolce, przewijają stronę
16

Test klawiaturą na stronie (2/2)

  • Esc · Zamyka okno dialogowe, menu albo podpowiedź. Fokus wraca w sensowne miejsce, zwykle do przycisku, który je otworzył
17

  • filetype: albo ext:: Windows Pliki jednego typu · Mac filetype:pdf
  • intitle:: Windows Słowo w tytule strony · Mac intitle:dostępność
  • allintitle:: Windows Wszystkie słowa w tytule strony · Mac allintitle:deklaracja dostępności
  • inurl:: Windows Słowo w adresie strony · Mac inurl:deklaracja-dostepnosci

Dorking: operatory wyszukiwania Google (2/3)

  • allinurl:: Windows Wszystkie słowa w adresie strony · Mac allinurl:bip deklaracja
  • intext:: Windows Słowo w treści strony · Mac intext:formularz
  • allintext:: Windows Wszystkie słowa w treści strony · Mac allintext:formularz zgłoszenia
  • "fraza": Windows Dokładnie ta fraza · Mac "deklaracja dostępności"
  • OR: Windows Jedno albo drugie, pisz wielkimi literami · Mac filetype:doc OR filetype:docx
