Część 1

Narzędzie

Instalacja, panel, ustawienia

3

Czym jest ARC Toolkit

  • Rozszerzenie DevTools od TPGi (Vispero): bezpłatne
  • Chrome i Firefox
  • Reguły ARC: te same co w płatnej platformie ARC
  • Działa lokalnie, także w ramkach iframe
4

Instalacja i start

  • Chrome Web Store albo Firefox Add-ons
  • DevTools: F12 albo Ctrl+Shift+I (Mac: Cmd+Option+I)
  • Zakładka ARC Toolkit na pasku DevTools
  • Plik z dysku: włącz „Allow access to file URLs”
5

Panel ARC

  • Run tests: wszystkie tematy albo jeden (All topics)
  • Lewa tabela: wyniki według elementów strony
  • Prawa część: wyniki według komunikatów (reguł)
  • Only Show: Errors, Alerts, Best Practices
6

Ustawienia

  • Koło zębate nad tabelą wyników
  • Use standard: WCAG 2.0, 2.1 albo 2.2
  • Use topics: tematy do testów
  • Domyślne typy wyników i wielkość czcionki panelu

Część 2

Wyniki

Errors, Alerts, Best Practices

8

Trzy typy wyników

  • Errors: znaleziony problem z dostępnością
  • Alerts: możliwy problem, sprawdź ręcznie
  • Best Practices: poza WCAG, ale wpływa na użytkowników
  • Każdy wynik ocenia człowiek
9

Tematy (topics)

  • 17 tematów, np. Images, Contrast, Keyboard
  • Interactive controls, Structure & semantics
  • Wybierasz temat z listy All topics
  • Temat to grupa reguł, nie kryterium WCAG
10

Szczegóły wyniku

  • Tytuł, opis i rekomendacja (po angielsku)
  • Kryteria WCAG przy wyniku
  • Lupa: Inspect element w panelu Elements
  • Schowek: Copy XPath do raportu
11

Highlight: wizualizacje

  • Highlight: zaznacz elementy na stronie
  • Grupy: Page, Medias, Structure, Keyboard, ARIA, Various
  • Np. Headings, Landmarks, Tables, Forms, Tab order
  • Klik w elemencie: czerwona ramka na stronie
12

Tab order

  • Highlight, grupa Keyboard, Tab order
  • Numery i linia: kolejność fokusu
  • Czego nie ma na ścieżce, nie dostanie fokusu
  • Fokus i jego widoczność sprawdzasz klawiszem Tab
13

Text Spacing i Page Reflow

  • Check Text Spacing: wymusza odstępy z 1.4.12
  • Check Page Reflow: okno 1280 px i powiększenie 400%
  • Patrzysz: czy treść się nie ucina i nie nakłada
  • Wynik ocenia człowiek, ARC tylko ustawia warunki
14

Other tools: uwaga na dane

  • Send URL albo Send selected DOM do walidatora W3C
  • ARIA Checker
  • Send: adres albo kod strony trafia do validator.w3.org
  • Strona klienta za logowaniem? Nie wysyłaj DOM bez zgody

Część 3

Ćwiczenia

Strona „Sklep z kubkami”

16

Ćwiczenie 1: Run tests

  • Otwórz plik „Sklep z kubkami” w Chrome
  • ARC Toolkit, Run tests
  • Zapisz liczby: Errors, Alerts, Best Practices
  • Przełącz widok: by elements, by messages
17

Co znalazł ARC: Errors

  • Obraz logo.png bez alt → 1.1.1
  • Pusty przycisk z ikoną SVG → 4.1.2
  • Pole E-mail bez nazwy → 4.1.2
  • Placeholder „Imię” zamiast etykiety → 3.3.2
  • Kontrast szarego tekstu → 1.4.3
18

Ćwiczenie 2: oceń Alerts

  • Only Show: zostaw tylko Alerts
  • Każdy: błąd, nie błąd albo nie dotyczy
  • Autocomplete: czy pole zbiera dane o użytkowniku?
  • Tabela „Produkt, Cena”: dane czy układ?
19

Ćwiczenie 3: klawiatura i odstępy

  • Highlight, Tab order: czy „Wyślij” jest na ścieżce?
  • Tab po stronie: czy widać fokus?
  • Check Text Spacing: czy tekst się nie nakłada?
  • Check Page Reflow: czy jest przewijanie w poziomie?

Część 4

ARC w audycie

Granice, porównanie, checklista

21

Czego ARC tu nie zgłosił

  • Div „Wyślij” z onclick bez roli i klawiatury
  • Dwa łącza „Czytaj więcej” do różnych miejsc
  • Tekst ukryty przez display:none
  • Nowe kryteria WCAG 2.2, np. 2.5.8, 2.4.11
22

Fałszywe alarmy i spory

  • Autocomplete: tylko pola o samym użytkowniku (1.3.5)
  • Placeholder: Error w ARC, Needs review w IBM
  • „Unknown table purpose”: decyzja, czy to dane
  • Best Practice to nie niezgodność z WCAG
23

ARC, IBM, WAVE, ANDI: kiedy które

  • WAVE: szybka mapa strony, ikony w treści
  • ANDI: nazwa i opis jednego elementu
  • IBM: lista według WCAG 2.2, wersja reguł, eksport
  • ARC: tematy, Tab order, Text Spacing, Page Reflow
24

Ten sam plik: ARC i IBM

  • Oba: obraz bez alt, pusty przycisk, pole bez nazwy, kontrast
  • Tylko ARC: przeskok h1 → h3, brak autocomplete
  • Tylko IBM: div „Wyślij” z onclick
  • Żaden: dwa łącza „Czytaj więcej” (ANDI tak)
25

Wynik ARC w raporcie

  • Narzędzie, wersja, standard, przeglądarka, data
  • Problem opisany po polsku, nie tytuł reguły
  • Kryterium WCAG: numer i nazwa
  • Miejsce (XPath), skutek, poprawka
26

Checklista audytora

  • Ustaw standard WCAG i zapisz wersję ARC
  • Każdy Error potwierdź w kodzie
  • Każdy Alert oceń i uzasadnij
  • Tab order, Text Spacing, Page Reflow: obejrzyj
  • Zawsze: klawiatura i czytnik ekranu
