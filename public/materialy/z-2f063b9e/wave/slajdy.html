Część 1

Narzędzie

Wersje, uruchomienie, panel

3

Czym jest WAVE

  • Zestaw narzędzi WebAIM (Utah State University)
  • Rozszerzenie przeglądarki i wersja online: bezpłatne
  • Wstawia ikony do strony, w miejscu problemu
  • WebAIM: „tylko człowiek ustali, czy strona jest dostępna”
4

Wersje WAVE

  • Rozszerzenie: Chrome, Firefox, Edge
  • Online: wave.webaim.org, wpisujesz adres
  • API i silnik do testów wielu stron (płatne usługi)
  • Do audytu: rozszerzenie
5

Uruchomienie

  • Ikona WAVE obok paska adresu
  • Windows: Ctrl+Shift+U · Mac: Cmd+Shift+U
  • Menu kontekstowe: „WAVE this page”
  • Wyłączenie: ikona jeszcze raz albo odświeżenie strony
6

Panel boczny

  • Summary: liczby w sześciu kategoriach
  • Details: lista wszystkich ikon, filtrowanie kategorii
  • Reference: opis ikony i powiązane kryteria WCAG
  • Order · Structure · Contrast: kolejność, struktura, kontrast
7

Styles, Order, Code

  • Styles OFF: strona bez CSS, widać kolejność w kodzie
  • Order: kolejność, rola i nazwa elementów interaktywnych
  • Code: kod strony z ikonami, na dole ekranu
  • Contrast: kalkulator i podgląd w skali szarości

Część 2

Wyniki

Co znaczą ikony i czego WAVE nie widzi

9

Sześć kategorii

  • Errors (czerwone): prawie na pewno problem
  • Contrast Errors: bardzo niski kontrast tekstu
  • Alerts (żółte): sprawdź ręcznie
  • Features (zielone): prawdopodobnie pomaga, też sprawdź
  • Structure i ARIA: informacja, nie ocena
10

Error, Alert, Feature

Error: <input> bez etykiety → **Missing form label**
Alert: przeskok h1 → h3 → **Skipped heading level**
Feature: alt="Mapa dojazdu" → **Alternative text**
Każdy z nich i tak oceniasz Ty
11

Najczęstsze błędy w WAVE

  • Missing alternative text → 1.1.1
  • Missing form label → 1.3.1, 3.3.2
  • Empty button · Empty link → 2.4.4 (i 4.1.2)
  • Language missing → 3.1.1 · Missing page title → 2.4.2
  • Very low contrast → 1.4.3
12

Ukryte elementy i fałszywe alarmy

  • WAVE bada też treść ukrytą: CSS, hidden, aria-hidden
  • Ikona ukrytego elementu w panelu jest przygaszona
  • Błąd w menu, które nigdy się nie pokaże: można pominąć
  • Kontrast: gradient, filtr, przezroczystość = brak wyniku
13

Mocne strony

  • Pokazuje problem w kontekście strony, nie w tabelce
  • Odsłania alt, etykiety, nagłówki, landmarki
  • Działa na stronach za logowaniem, bez wysyłania danych
  • Dokumentacja każdej ikony z kryteriami WCAG

Część 3

WAVE w audycie

Przykład, procedura, raport

15

Przykład: formularz kontaktowy

<input type="text" placeholder="Imię">
<input type="email" id="mail"> + <label for="email">
<button><img src="wyslij.svg"></button>
<div class="btn" onclick="wyslij()">Wyślij</div>
16

Co pokazał WAVE

  • Imię: Missing form label (error) → 1.3.1, 3.3.2
  • E-mail: Orphaned form label (alert) → 1.3.1, 4.1.2
  • Przycisk z obrazkiem: Empty button (error) → 4.1.2
  • Div z onclick: często cisza → 2.1.1, 4.1.2 tylko ręcznie
17

Czego WAVE nie sprawdzi

  • Czy wszystko działa z klawiatury i widać fokus (2.1.1, 2.4.7)
  • Czy alt i etykiety mają sens (1.1.1, 2.4.6)
  • Czy kolejność czytania jest logiczna (1.3.2, 2.4.3)
  • Czy komunikaty błędów słychać w czytniku (3.3.1, 4.1.3)
  • Kontrast elementów graficznych, zoom, reflow (1.4.11, 1.4.10)
18

Procedura testowa

  • 1. Uruchom WAVE, zapisz Summary
  • 2. Errors i Contrast Errors: potwierdź każdy w Code
  • 3. Alerts: oceń, odrzuć albo przenieś do błędów
  • 4. Structure, Order, Styles OFF: mapa i kolejność
  • 5. Test ręczny: klawiatura, czytnik, zoom
19

Wynik WAVE w raporcie

  • Narzędzie, wersja, przeglądarka, data, adres
  • Problem opisany słowami, nie nazwą ikony
  • Kryterium WCAG: numer i nazwa
  • Miejsce w kodzie, skutek dla użytkownika, poprawka
20

WAVE na tle innych narzędzi

  • axe DevTools: lista wyników w DevTools, silnik axe-core
  • ARC Toolkit: panel w DevTools, mocny w strukturze i ARIA
  • Lighthouse: wbudowany w Chrome, część testów axe-core
  • SiteLint: testy automatyczne i monitoring wielu stron
  • Różne silniki = różne wyniki. Warto mieć dwa.
21

Ćwiczenie

  • a11yfirst.pl/plac-zabaw-html
  • Przykład: „strona z błędami (do poprawy)”
  • „Pobierz .html”, otwórz plik, uruchom WAVE
  • Zapisz 3 błędy z kryterium WCAG
22

Do zabrania

  • WAVE pokazuje, gdzie patrzeć, nie wydaje werdyktu
  • Error potwierdzasz, alert oceniasz, feature też sprawdzasz
  • Zero błędów to początek audytu, nie koniec
  • W raporcie: kryterium, skutek, poprawka
